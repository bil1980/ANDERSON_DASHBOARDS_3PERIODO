Descrição do Sistema

O BilzarPub é um sistema criado para ajudar no controle e na organização de eventos realizados em um espaço de festas. Nele são armazenadas informações sobre clientes, festas, DJs, salões e contratos, facilitando o gerenciamento de todos os dados em um único lugar.

Através do sistema é possível cadastrar clientes, registrar os salões disponíveis para aluguel, armazenar informações dos DJs e controlar as festas agendadas. Cada evento possui dados como tema, data, horário, quantidade de convidados e valor total, permitindo um acompanhamento mais organizado das atividades do estabelecimento.

Tecnologias Utilizadas


PostgreSQL: Armazenamento e gerenciamento do banco de dados.

Python: Desenvolvimento da aplicação e execução das consultas.

Pandas: Manipulação dos dados retornados pelo banco.

Plotly: Criação dos gráficos e dashboard interativo.

VS Code: Ambiente utilizado para desenvolvimento do projeto.
